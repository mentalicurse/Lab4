# Lab4 - Шифрование и дешифрование папок
Lab4 - консольное приложение для рекурсивного шифрования и дешифрования всех файлов в указанной директории и ее подпапках. Используется алгоритм шифрования AES-256.
#
### Постановка задачи
* Реализовать защиту данных пользовательских папок и файлов находящихся в папке, а также подпапках путем шифрования. 
* Для доступа к данным исходной папке необходимо выполнить дешифрование.
* Использовать паттерн Singleton для управления процессом.
###
### Требования
* ОС Linux
* CMake версии 3.10 и выше
* Компилятор с поддержкой C++17
* Библиотека Crypto++
###
### Установка зависимостей
```
 sudo apt update
 sudo apt install -y libcrypto++-dev libcrypto++-utils //установка Crypto++
 sudo apt install -y pkg-config //установка pkg-config
```
###
### Сборка проекта
```
git clone <адрес_репозитория>
cd Lab4
mkdir build && cd build
cmake ..
make
```
###
### Запуск проекта
```
./main
```
